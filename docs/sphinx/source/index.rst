.. rubric:: :header_no_toc:`LVM Data Reduction Pipeline`

The LVM Data Reduction Pipeline (``lvmdrp``) reduces the raw data of the SDSS-V
Local Volume Mapper into calibrated, sky-subtracted spectra, and makes the master
calibrations it needs. It is based on routines from
`Py3D <https://github.com/brandherd/Py3D>`_.

The `README <https://github.com/sdss/lvmdrp/blob/dev/README.md>`_ on GitHub is the
guide to installing and running the DRP. The pages below describe it in more depth.
